# دیدار | داشبورد منابع انسانی الکتروکویر

داشبورد فارسی و راست‌چین Next.js برای ارائه، با دادهٔ نمونهٔ ۴۰۰ نفر در تهران و یزد.

```bash
npm ci
npm run dev -- --hostname 0.0.0.0
```

`npm run build` ساخت تولید و `npm run typecheck` بررسی تایپ‌ها را اجرا می‌کند.

فایل اکسل ورودی، فهرست فیلدها و مرجع آن‌ها را دارد. این فهرست در `lib/sources.json` و بخش «منابع داده» در دسترس است. شاخص‌های دمو از `lib/dashboard.ts` می‌آیند. برای اتصال واقعی، تجمیع داده‌های راهکاران، کسری، BPMS و سایر مراجع باید سمت سرور انجام شود. برای محیط عملیاتی، احراز هویت، کنترل دسترسی و تعریف دقیق شاخص‌ها پیش از دسترسی به داده‌های پرسنلی لازم است.

## نقشهٔ یزد

در صفحهٔ «سرویس کارکنان»، یک‌بار با اینترنت روی «به‌روزرسانی نقشه» بزنید تا دادهٔ خیابان‌ها و مکان‌های ثبت‌شده در OpenStreetMap از `overpass-api.de` دریافت شود. نقشه و جست‌وجوی محلی در همان مرورگر و نشانی برنامه ذخیره می‌شوند. اجرای محلی با `localhost` یا میزبانی با HTTPS برای ذخیرهٔ آفلاین لازم است. در اجرای محلی، سرور Next.js با قطع اینترنت همچنان باید روشن باشد. پوشش جست‌وجوی محلی به آدرس‌ها و نام‌های ثبت‌شده در دادهٔ دانلودی بستگی دارد. دکمهٔ «جست‌وجوی آنلاین» اختیاری است و به `nominatim.openstreetmap.org` نیاز دارد.

ویرایش مسیرها جداگانه در مرورگر ذخیره می‌شود. دانلود نسخهٔ جدید نقشه مسیرهای سرویس را بازنویسی نمی‌کند.

## تقویم و کارهای روزانه

تقویم شمسی، جمعه‌ها و تعطیلات رسمی سال‌های ۱۴۰۴ تا ۱۴۰۶ را از بستهٔ `@avan-persian/holidays` نمایش می‌دهد. برای سال‌های دیگر، جمعه‌ها و تعطیلات ثابت شمسی در دسترس‌اند. کارهای روزانه در همان مرورگر ذخیره می‌شوند و خروجی `.ics` برای وارد کردن در برنامه‌های تقویم ارائه می‌شود.
