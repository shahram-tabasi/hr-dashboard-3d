# دیدار | داشبورد منابع انسانی الکتروکویر

داشبورد فارسی و راست‌چین Next.js برای ارائه، با دادهٔ نمونهٔ ۴۰۰ نفر در تهران و یزد.

## استقرار با Docker Compose

روی سرور، Docker Engine و افزونهٔ Docker Compose لازم است. Node.js و npm داخل تصویر نصب هستند.

```bash
docker compose up -d --build --wait
docker compose ps
```

داشبورد روی پورت ۳۰۰۰ در دسترس است. برای انتخاب پورت دیگری می‌توانید فرمان را به شکل `DASHBOARD_PORT=8080 docker compose up -d --build --wait` اجرا کنید. برای مشاهدهٔ لاگ از `docker compose logs -f dashboard` استفاده کنید.

برای به‌روزرسانی، `git pull --ff-only origin main` و سپس همان فرمان `docker compose up` را اجرا کنید. برای استفاده از قابلیت نقشهٔ آفلاین در مرورگر راه دور، داشبورد را با HTTPS ارائه کنید یا از تونل SSH و نشانی `http://localhost:3000` استفاده کنید.

### ساخت از طریق Harbor

اگر Docker Hub در دسترس نیست، تصویر پایهٔ هر دو مرحله را از پروژهٔ خصوصی `docker-proxy` بگیرید:

```bash
docker login registry.simorghai.com
NODE_IMAGE=registry.simorghai.com/docker-proxy/library/node:24-bookworm-slim docker compose up -d --build --wait
```

می‌توانید `NODE_IMAGE` را در فایل محلی `.env` ثبت کنید تا در ساخت‌های بعدی هم استفاده شود. نصب بسته‌های قفل‌شده همچنان به دسترسی کانتینر ساخت به `registry.npmjs.org` نیاز دارد.

## اجرای محلی برای توسعه

برای اجرای محلی به Node.js نسخهٔ ۲۲.۱۳ یا جدیدتر نیاز دارید.

```bash
npm ci
npm run dev -- --hostname 0.0.0.0
```

`npm run build` ساخت تولید و `npm run typecheck` بررسی تایپ‌ها را اجرا می‌کند.

فایل اکسل ورودی، فهرست فیلدها و مرجع آن‌ها را دارد. این فهرست در `lib/sources.json` و بخش «منابع داده» در دسترس است. شاخص‌های دمو از `lib/dashboard.ts` می‌آیند. برای اتصال واقعی، تجمیع داده‌های راهکاران، کسری، BPMS و سایر مراجع باید سمت سرور انجام شود. برای محیط عملیاتی، احراز هویت، کنترل دسترسی و تعریف دقیق شاخص‌ها پیش از دسترسی به داده‌های پرسنلی لازم است.

## نقشهٔ یزد

نقشهٔ سرویس‌ها در «نمای کلی» و «سرویس کارکنان» به‌صورت پیش‌فرض با نمای نقطه‌ای محلی یزد باز می‌شود. نسخهٔ همراه برنامه مختصات مرکز قطعات خیابان و نام‌های موجود را دارد و به اتصال مرورگر به سرویس نقشه نیاز ندارد. [منبع و مجوز داده](public/maps/README.md).

برای نمایش خطوط کامل خیابان‌ها، «به‌روزرسانی آنلاین» را بزنید اگر سرور به Overpass دسترسی دارد. همچنین می‌توانید یک فایل GeoJSON یزد با عوارض LineString یا MultiLineString را از گزینهٔ «ورود فایل GeoJSON» وارد کنید. برای نمونه در Overpass Turbo، پرس‌وجوی زیر را اجرا و خروجی GeoJSON را دریافت کنید:

```
[out:json][timeout:45];
way["highway"](31.81,54.27,31.96,54.46);
out geom;
```

لایهٔ خطی و جست‌وجوی محلی در IndexedDB همان مرورگر ذخیره می‌شوند. اگر به‌روزرسانی آنلاین ناموفق باشد، نقشهٔ محلی موجود همچنان قابل استفاده است. پوشش جست‌وجوی محلی به نام‌های ثبت‌شده در داده بستگی دارد. دکمهٔ «جست‌وجوی آنلاین» اختیاری است و به `nominatim.openstreetmap.org` نیاز دارد.

ویرایش مسیرها جداگانه در مرورگر ذخیره می‌شود. دانلود نسخهٔ جدید نقشه مسیرهای سرویس را بازنویسی نمی‌کند.

## تقویم و کارهای روزانه

تقویم شمسی، جمعه‌ها و تعطیلات رسمی سال‌های ۱۴۰۴ تا ۱۴۰۶ را از بستهٔ `@avan-persian/holidays` نمایش می‌دهد. برای سال‌های دیگر، جمعه‌ها و تعطیلات ثابت شمسی در دسترس‌اند. کارهای روزانه در همان مرورگر ذخیره می‌شوند و خروجی `.ics` برای وارد کردن در برنامه‌های تقویم ارائه می‌شود.


## گزارش مدیریت منابع انسانی

واحدهای سازمانی بر اساس چارت ۱۴۰۵/۰۵/۰۴ تعریف شده‌اند. نفرات، جنسیت، دریافتی، وام‌ها، مرخصی و نسبت محل خدمت دادهٔ نمایشی هستند. مبالغ به تومان است. منابع واقعی باید پس از تعریف قرارداد داده و دسترسی مجاز وصل شوند. «کارا» در فهرست منابع ثبت شده است.

### اتصال دستیار محلی

در `.env` استقرار، `LOCAL_MODEL_URL` را روی نشانی کامل OpenAI-compatible مانند `http://MODEL_HOST:8000/v1/chat/completions` و `LOCAL_MODEL_NAME` را روی شناسهٔ مدل تنظیم کنید. در صورت نیاز `LOCAL_MODEL_KEY` را در همان فایل اضافه کنید. نشانی باید از داخل کانتینر در دسترس باشد. سپس سرویس را با `docker compose up -d` دوباره ایجاد کنید. دستیار با API سمت سرور کار می‌کند و زمینهٔ خودکار آن فقط خلاصهٔ تجمیعی دادهٔ نمونه است.


## صندوق انتقادات و پیشنهادات

لینک مستقیم فرم `/feedback` را با گزینهٔ «کپی لینک» در «صندوق انتقادات و پیشنهادات» بردارید و در اختیار کارکنان قرار دهید. کارکنان می‌توانند پیام را با نام یا بدون نام ثبت کنند. برای باز کردن «صندوق انتقادات و پیشنهادات»، در فایل `.env` استقرار مقدار `HR_INBOX_PASSWORD` را با یک رمز طولانی و تصادفی تنظیم کنید و سرویس را دوباره بالا بیاورید. برای استفادهٔ سازمانی، نشانی را با HTTPS ارائه کنید.

پیام‌ها در پایگاه SQLite روی والیوم `feedback-data` ذخیره می‌شوند. بازسازی کانتینر پیام‌ها را حفظ می‌کند. حذف والیوم، پایگاه پیام‌ها را هم حذف می‌کند. در اجرای محلی، متغیر رمز را در `.env.local` تنظیم کنید. مسیر پیش‌فرض پایگاه محلی `.didar-data/` است.
