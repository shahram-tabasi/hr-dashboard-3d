# Yazd offline street index

Source: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/). The [Yazd extract published by Hud2 Offline Data](https://github.com/babakriazi/Hud2-Offline-Data/releases/tag/v20261125) is derived from the [Geofabrik Iran extract](https://download.geofabrik.de/asia/iran.html).

The included JSON is the OSM street-segment midpoint and name index from `yazd-roads.json.gz` v20261125, filtered to latitude 31.81–31.96 and longitude 54.27–54.46, rounded to five decimal places, and deduplicated. It contains geographic points, with names where supplied. It has no full road geometry. The in-app OpenStreetMap attribution covers both the packaged index and any OpenStreetMap update.
